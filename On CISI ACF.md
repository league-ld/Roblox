# CISI Anti-Cheat Framework

I have been working on a revolutionary client-sided Anti-Cheat Framework which allows developers to integrate client-sided cheat detection. This has the benefit of being able to read client-sided values(such as camera CFrame, which would be beneficial for Aimbot detection).
Client-sided ACs are uncommon on Roblox due to how easily they can be bypassed by bad actors. This is what CISI aims to fix. CISI provides a foundation upon which to build the AC and have near-guaranteed security.
CISI is currently functional, with demo video on my YouTube channel, but it is still not as powerful as it's meant to be. It is being actively worked on.
CISI uses an innovative technology which makes it difficult for exploiters to even find the detection code.
Whether I will open source CISI or not I have not yet decided. For now I am open to selling a commercial use license.
